# Два ИИ на стройке

Интерактивный гид «Какого хрена, нейросети?»: как организовать совместную работу ChatGPT и Claude на реальном ремонте квартиры. Роли, протоколы, музей пойманных ошибок и квизы.

Открыть: https://groman69-cloud.github.io/dva-ii-na-stroike/

Имена подрядчиков и адрес убраны, название ЖК вымышленное. Суммы и размеры настоящие.
